# Run the fixer under the reviewer's isolation

Labels: task, P1
Milestone: 0.4.0

## Purpose

The fixer runs on the same pull request as the reviewer, with fewer limits on
what it can do. Run it under the isolation the reviewer already has.

## Acceptance criteria

- [ ] The fixer's Copilot run passes `--disable-builtin-mcps`, `--no-auto-update`
      and `--disable-client-telemetry`, as `reviewerArgs` does
- [ ] The fixer's shell grant allows only the commands the project's checks run.
      `Bash(git:*)` goes: `git -c alias.x='!cmd' x` runs any command
- [ ] The fixer's prompt stops forbidding `squiz review`, which its handoff asks
      it to run once it has pushed
- [ ] `npm run typecheck && npm test` pass
