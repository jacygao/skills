# Say which round a handoff belongs to in its file name

Labels: task
Milestone: 0.4.0

## Purpose

Every headless round overwrites `.squiz/handoff.md`, so an earlier round's handoff is lost.

## Acceptance criteria

- [ ] A headless round writes its handoff to `.squiz/handoff-<round>.md`
- [ ] `npm run typecheck && npm test` pass
