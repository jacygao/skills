# Show the reviewer's model in squiz doctor

Labels: task, P2
Milestone: 0.4.0

## Purpose

`squiz doctor` names the reviewer but not the model it runs, so a wrong model in
`.squiz.json` goes unnoticed until a review.

## Acceptance criteria

- [ ] `squiz doctor` prints the model from `.squiz.json`, or the reviewer's
      default when the file names none
- [ ] `npm run typecheck && npm test` pass
