# Start a fixer on a headless round's handoff

Labels: task, P1
Milestone: 0.4.0

## Purpose

A headless run writes each round's handoff to `.squiz/handoff.md` and stops, so
nobody works the findings until a person reads them. Start a fixer on it.

## Acceptance criteria

- [ ] A headless round that ends with findings starts a fixer on its handoff,
      on the model `.squiz.json` names
- [ ] `npm run typecheck && npm test` pass
