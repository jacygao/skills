# Check the Copilot validation agent on the 15 senior design tasks it alone grades

## Purpose

Show that senior's validation agent, run through Copilot CLI since #281, grades the design tasks as senior's own grader does before a senior arm is ranked on it.

## Acceptance criteria

- [ ] On each of the 15 design tasks the validation agent alone grades, it passes the reference fix and fails an unchanged repository, recorded in a note beside the mini-swe-agent result (14 of 15)
- [ ] Three of those reference fixes graded a second time agree with their first grading, or the note says how often they disagree
- [ ] The note records the AI credits and the time each grading took
- [ ] It confirms in a real container what #281's tests could not: Copilot CLI runs from `test.sh`, `--secret-env-vars` keeps the token out of the agent's shell commands, and a session that hits `--max-ai-credits` is not recorded as `ok`
