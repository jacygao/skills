How a project's specification is written and edited: a fixed heading
structure, and only requirements a user, a caller or another program can
observe, each stated once, so the spec stays the size of the product.

## Load it

Its description loads it before writing or editing a spec, and again before
rewriting a section.

## What to add to AGENTS.md

```markdown
## Skills

- Load `writing-specs` before editing `docs/specs/`.

## Specification

- `docs/specs/<project>-spec.md` is the main specification.
```

Specs live in `docs/specs/` unless `AGENTS.md` says otherwise. The main
specification is the worked example of structure and voice, and prose rules
such as `.claude/rules/prose.md` govern its sentences where the project has
them.
